# Reference build — Grok Bot

The look every Blue Motion piece follows was approved on this build, and the 13 templates in
`library/scenes/` were extracted from it. Use it to **see** a finished result, not as a starting
point — new work starts from `library/`.

| Folder | What |
|---|---|
| `grok-bot/renders/agent-fleet.mp4` | A finished 7s beat (muted). Watch this first. |
| `grok-bot/renders/agents-version-of-you.mp4` | A finished 14s beat (muted). |
| `grok-bot/*/snapshots/contact-sheet.jpg` | Frame grids of each project. |
| `grok-bot/*/compositions/` + `index.html` | Scene source, for reading. Media (VO, footage) is not in the repo, so these projects do not preview from here. |
| `grok-bot/design.md` | What was specific to that build: resolved logos, real footage framed by a scene. |

Paths inside these notes may still say `Grok Bot/`; that is `reference/grok-bot/` in this repo.
